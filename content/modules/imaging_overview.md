# Computer Imaging Overview

## Goal

Understand what computer imaging is, why IT departments use it, and how IT work-study students may safely assist with imaging-related tasks.

As a new IT work-study student, you do not need to fully run or manage the imaging process. The goal is to understand the concept, recognize common terms, follow safe boundaries, document what you see, and ask a mentor before making decisions.

---

## Plain-Language Explanation

**Computer imaging** is the process of preparing a computer with the required operating system, software, settings, and configuration.

In simple terms:

> Imaging gets a computer ready for use.

Instead of setting up every computer manually from scratch, IT departments may use an imaging process to prepare computers in a more consistent way.

A completed image may include:

- Operating system
- Required software
- Security settings
- Department settings
- User or lab configuration
- Updates
- Device management tools

Imaging helps make sure computers are prepared the same way and are ready for the correct user, department, classroom, or lab.

---

## Why This Matters

Imaging matters because a computer that is not prepared correctly can cause problems later.

For example:

- Required software may be missing.
- Settings may be wrong.
- The computer may not work correctly on the network.
- The wrong user or department may receive the wrong setup.
- Extra technician time may be needed to fix mistakes.

For IT work-study students, imaging can feel confusing because it involves terms like:

- Image
- Task sequence
- Deployment
- SCCM / Configuration Manager
- Asset tag
- Inventory
- Workbench
- Error code

You do not need to master all of this immediately. You do need to understand that imaging is important, and you should not guess during imaging-related work.

---

## Key Terms

### Imaging

Imaging is the process of preparing a computer with the required operating system, software, settings, and configuration.

It is commonly used when preparing:

- New computers
- Reused computers
- Lab computers
- Classroom computers
- Replacement devices

---

### Image

An image is a prepared computer setup.

An image may include:

- Operating system
- Software
- Settings
- Configuration
- Department-specific requirements

Different computers, labs, or departments may use different images.

Do not guess which image to use.

---

### Operating System

An operating system is the main software that allows a computer to run.

Examples:

- Windows
- macOS
- Linux

Many college or workplace computers use a standard operating system setup chosen by IT.

---

### Software

Software refers to programs or applications installed on a computer.

Examples:

- Microsoft Office
- Web browsers
- Adobe applications
- Classroom software
- Department-specific tools

A correctly imaged computer should have the software it needs for its purpose.

---

### Configuration

Configuration means the settings and setup applied to a computer.

Examples:

- Network settings
- Security settings
- Device name
- Management settings
- Installed applications
- Department-specific setup

---

### SCCM / Configuration Manager

SCCM is a name many IT staff still use for Configuration Manager.

Configuration Manager may be used to manage computers, deploy software, install updates, and support imaging workflows.

As a work-study student, you mainly need to understand that it may be involved in imaging. You should not make Configuration Manager changes unless trained and authorized.

---

### Task Sequence

A task sequence is a set of steps used during imaging or deployment.

A task sequence may tell the system to:

- Prepare the computer
- Install the operating system
- Apply settings
- Install software
- Restart the computer
- Run additional setup steps

Do not choose or edit task sequences unless you are specifically trained and authorized.

---

### Deployment

A deployment is when software, updates, settings, or operating system instructions are sent to computers.

Imaging may involve deployment steps.

If a deployment fails, document the error and ask your mentor.

---

### Asset Tag

An asset tag is a label or ID used to track equipment.

Before or after imaging, asset tag information may be used to confirm the correct computer is being worked on.

Do not remove, change, or guess asset tag information.

---

### Inventory

Inventory is the system or process used to track equipment.

Inventory may include:

- Device name
- Asset tag
- Serial number
- Location
- Assigned user
- Status

A computer may need inventory updates before or after imaging, depending on department procedure.

---

### Workbench

A workbench is an IT area where devices may be prepared, checked, imaged, repaired, or reviewed.

Work-study students may help move devices to or from a workbench if instructed.

---

### Error Code

An error code is a message, number, or code that helps identify what went wrong.

If an error appears during imaging, write it down exactly and ask your mentor.

---

### Post-Image Check

A post-image check is a review after imaging to confirm the computer appears ready.

Depending on department procedure, this may include checking:

- The computer starts correctly
- Required software is present
- Network connection works
- Device information is correct
- No obvious errors appear

As a new work-study student, only complete post-image checks you have been trained to do.

---

## What You Need to Know

As a new IT work-study student, you should understand these basic ideas:

1. Imaging prepares a computer for use.
2. Imaging is important because the wrong setup can affect users, classrooms, labs, or departments.
3. Different devices may require different images or workflows.
4. You should not guess which image, task sequence, or workflow applies.
5. You may help with beginner-safe preparation and documentation tasks.
6. If an error appears, stop and ask for help.
7. A computer looking “done” does not always mean it is ready for the user.
8. Mentor or supervisor approval may be required before marking a device complete.

---

## Beginner-Safe Things You Can Do

Depending on department procedure, beginner-safe actions may include:

- Move a computer to the workbench if instructed.
- Confirm the computer has power.
- Connect monitor, keyboard, mouse, network cable, and power if instructed.
- Check the asset tag or label.
- Record the device name or asset tag.
- Observe the imaging process.
- Watch for visible error messages.
- Write down an error code exactly as shown.
- Tell your mentor what step you were on when the error appeared.
- Prepare a draft note or mentor summary if instructed.

These actions support the imaging workflow without requiring you to make restricted decisions.

---

## What You Should Not Do Without Approval

Do not do these unless you are specifically trained and authorized:

- Choose an image by guessing.
- Choose or edit a task sequence.
- Change imaging settings.
- Use admin credentials.
- Rerun imaging repeatedly without telling anyone.
- Ignore error messages.
- Mark a device complete if you are unsure.
- Work on a computer if you are unsure it is the correct device.
- Remove or change asset tags.
- Skip documentation.
- Create, edit, close, or update tickets/work orders until you are trained and authorized.
- Tell someone the computer is ready if you are not sure.

When in doubt, stop and ask.

---

## Common Beginner Mistakes

New work-study students may accidentally:

- Think every computer uses the same image.
- Assume “the computer turned on” means imaging is complete.
- Ignore an error message because the process kept going.
- Forget to write down the exact error.
- Work on the wrong device.
- Skip asset tag or inventory checks.
- Mark something complete before a mentor confirms it.
- Feel embarrassed asking what imaging means.
- Continue clicking because they do not want to bother anyone.

These mistakes are common for beginners, but they are preventable.

The safest habit is:

> Stop, document what happened, and ask your mentor.

---

## When to Ask for Help

Ask your mentor, IT tech, or supervisor when:

- You are not sure which device you are working on.
- You are unsure which image or workflow applies.
- You see an unfamiliar error.
- A task sequence fails.
- The imaging process stops unexpectedly.
- The device is missing an asset tag or label.
- The device does not appear in inventory.
- You are unsure whether the computer is ready.
- You are tempted to guess.
- You are not sure what details to give your mentor for the ticket/work order.

Imaging can affect the computer’s setup, software, user experience, and department readiness. It is better to ask early than to create extra work later.

## Example Student Questions

### “What does imaging actually mean?”

Imaging means preparing a computer with the required operating system, software, settings, and configuration so it is ready for the correct use.

---

### “Do I need to know how to image computers by myself?”

Not at first.

As a new work-study student, you mainly need to understand what imaging is, how to assist safely, what not to touch without approval, and when to ask a mentor.

---

### “What should I do if an imaging error appears?”

Stop and document:

- Device name or asset tag
- Error message or code
- What step was happening
- What you were asked to do
- Whether anything changed

Then ask your mentor or the IT tech on duty.

---

### “What if I do not know which image to use?”

Do not guess.

Ask your mentor or the IT tech on duty. Using the wrong image may configure the computer incorrectly for the user, department, classroom, or lab.

---

### “What should I tell my mentor for the ticket/work order?”

A helpful draft note or mentor summary might be:

> Observed imaging issue on device ____. Error shown: ____. I stopped before continuing and notified mentor/on-shift tech for next steps.

Do not enter this into the ticket/work-order system yourself until you have been trained and approved to do so.
