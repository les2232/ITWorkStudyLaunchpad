# SCCM / Configuration Manager Overview

## Goal

Understand what SCCM / Configuration Manager is, why IT departments use it, and how it relates to computer imaging, software deployment, updates, and managed computers.

As a new IT work-study student, you do not need to administer Configuration Manager. The goal is to understand the basic idea so you can follow conversations, recognize when it is involved, and know when to ask a mentor for help.

---

## Plain-Language Explanation

**SCCM** is a name many IT people still use for **Configuration Manager**.

In simple terms:

> Configuration Manager is a tool IT departments use to manage computers.

It can help IT staff:

- Prepare computers
- Deploy software
- Install updates
- Manage settings
- Track devices
- Support computer imaging

You may hear techs say things like:

- “Check SCCM.”
- “The task sequence failed.”
- “This machine is not showing up.”
- “The deployment did not run.”
- “The image failed.”
- “Is this device in the right collection?”

Those phrases can sound intimidating at first. You do not need to understand every detail right away. You just need to understand that SCCM / Configuration Manager is part of how IT manages computers at scale.

---

## Why This Matters

Configuration Manager matters because IT departments often support many computers, not just one.

Instead of manually setting up every computer one by one, IT can use management tools to help standardize and automate work.

For example, Configuration Manager may help with:

- Preparing new or reused computers
- Installing required software
- Applying updates
- Running imaging workflows
- Organizing computers into groups
- Tracking whether deployments succeeded or failed

For work-study students, this matters because you may help with the physical and documentation parts around these workflows.

You may be asked to:

- Move computers to a workbench
- Connect power, network, monitor, keyboard, and mouse
- Confirm asset tags or labels
- Observe an imaging process
- Write down an error message
- Update a ticket with what happened
- Ask a mentor when something does not look right

---

## Key Terms

### SCCM

SCCM stands for **System Center Configuration Manager**.

Many IT staff still say “SCCM” out of habit, even when referring to Configuration Manager.

As a work-study student, treat SCCM and Configuration Manager as closely related terms unless your mentor explains a specific difference in your environment.

---

### Configuration Manager

Configuration Manager is a tool used to manage computers, software, updates, operating system deployment, and related IT workflows.

You do not need to administer it as a new work-study student.

You should understand that it may be involved when people discuss:

- Imaging
- Software installs
- Updates
- Device collections
- Deployments
- Task sequences

---

### Managed Computer

A managed computer is a device that IT can control, monitor, update, or configure through approved tools and procedures.

A managed computer may receive:

- Software
- Updates
- Security settings
- Configuration changes
- Imaging workflows

---

### Deployment

A deployment is when software, updates, settings, or operating system instructions are sent to one or more computers.

Example:

> IT deployed software to a group of lab computers.

A deployment may succeed, fail, or still be in progress.

---

### Collection

A collection is a group of devices or users.

IT staff may use collections to organize which computers receive a deployment.

Example:

> Lab computers may be in one collection, while staff computers may be in another.

As a new work-study student, do not add or remove devices from collections unless specifically trained and authorized.

---

### Imaging

Imaging is the process of preparing a computer with the required operating system, software, settings, and configuration.

Configuration Manager may be part of the imaging process.

You should not guess which image or workflow to use.

---

### Image

An image is a prepared setup used to configure a computer.

Different computer types, labs, or departments may need different images.

Do not choose an image by guessing.

---

### Task Sequence

A task sequence is a set of steps used during imaging or deployment.

A task sequence may include steps such as:

- Preparing the disk
- Installing the operating system
- Applying settings
- Installing software
- Running scripts
- Restarting the computer

As a work-study student, you may hear this term during imaging. You should not edit or choose task sequences unless trained and authorized.

---

### Distribution Point

A distribution point is a location where deployment files may be stored so computers can access them.

If a computer cannot get the files it needs, a tech may investigate whether it can reach the correct distribution point.

As a beginner, you only need to know that deployment files have to come from somewhere.

---

### Client

The client is the software on a managed computer that allows it to communicate with Configuration Manager.

If a tech says “the client is not checking in,” they may mean the computer is not communicating properly with the management system.

---

### Error Code

An error code is a message or number that helps identify what went wrong.

If you see an error code during imaging or deployment, do not ignore it.

Write it down exactly and ask your mentor.

---

### Workbench

A workbench is an IT area where devices may be prepared, checked, imaged, repaired, or reviewed.

Work-study students may help move equipment to or from a workbench if instructed.

---

## What You Need to Know

As a new IT work-study student, you should understand these basic ideas:

1. SCCM / Configuration Manager is used to manage computers.
2. It may be involved in imaging, software deployment, updates, and device organization.
3. You do not need to administer it as a beginner.
4. You should not guess which image, collection, or task sequence to use.
5. If an imaging or deployment error appears, document it and ask for help.
6. Your role may involve preparing devices, checking labels, connecting cables, observing, and documenting status.
7. Restricted settings, admin tools, and deployment decisions should be handled by trained IT staff.

---

## Beginner-Safe Things You Can Do

Depending on department procedure, beginner-safe actions may include:

- Move a device to the workbench if instructed.
- Confirm the computer has power.
- Connect keyboard, mouse, monitor, and network cable if instructed.
- Check the asset tag or label.
- Record the device name or asset tag.
- Watch for visible error messages.
- Write down an error code exactly as shown.
- Tell your mentor what step you were on when the error appeared.
- Update a ticket with approved notes.

These actions help the team without requiring you to change restricted settings.

---

## What You Should Not Do Without Approval

Do not do these unless you are specifically trained and authorized:

- Choose an image by guessing.
- Choose or edit a task sequence.
- Add or remove devices from collections.
- Change Configuration Manager settings.
- Use admin credentials.
- Restart or rerun imaging repeatedly without telling anyone.
- Mark a device complete if you are unsure.
- Ignore error messages.
- Work on a device if you are unsure it is the correct one.

When in doubt, stop and ask.

---

## Common Beginner Mistakes

New work-study students may accidentally:

- Think SCCM is only used for imaging.
- Assume every computer uses the same image.
- Ignore an error because the computer “looks done.”
- Forget to write down the exact error message.
- Continue clicking through options without understanding them.
- Mark a computer complete before checks are finished.
- Feel embarrassed asking what SCCM means.
- Assume “deployment finished” means “ready for the user.”

These mistakes are understandable, but they can create extra work later. The safest habit is:

> Stop, document what happened, and ask your mentor.

---

## When to Ask for Help

Ask your mentor, IT tech, or supervisor when:

- You do not know what SCCM / Configuration Manager means in the current task.
- You are unsure which image or workflow applies.
- A task sequence fails.
- An error code appears.
- The device does not appear to be imaging correctly.
- The device is missing an asset tag or label.
- You are unsure whether the device is ready.
- You are tempted to guess.
- You are not sure what to write in the ticket.

Imaging and deployment workflows can affect the device, user experience, software, and data. Ask early.

## Example Student Questions

### “Is SCCM the same thing as Configuration Manager?”

In many conversations, yes. Many IT staff still say SCCM when talking about Configuration Manager.

For your role, it is okay to understand them as closely related unless your mentor explains a specific difference.

---

### “Do I need to know how to use SCCM?”

Not fully.

As a new work-study student, you mainly need to understand what it is used for and how it relates to imaging, deployments, and managed computers.

You should not use admin tools or make deployment decisions unless specifically trained and authorized.

---

### “What should I do if a task sequence fails?”

Stop and document:

- The device name or asset tag
- The error message or code
- What step was happening
- What you were asked to do
- Whether anything changed

Then ask your mentor or the IT tech on duty.

---

### “What if I do not know which image to use?”

Do not guess.

Ask your mentor or the IT tech on duty. Using the wrong image can create extra work and may make the computer unsuitable for the user or location.

---

### “What should I write in the ticket?”

A helpful ticket note might include:

> Observed imaging issue on device ____. Error shown: ____. I stopped before continuing and notified mentor/on-shift tech for next steps.
