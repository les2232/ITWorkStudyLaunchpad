# IT Work Study Launchpad Pre-Assessment v1

## Purpose

This assessment helps determine each new IT work-study student's starting knowledge, confidence level, and recommended training path.

It is not pass/fail. The goal is to understand what the student already knows so they can receive the right training and support.

## Student Intro

Welcome to the IT Work Study Launchpad pre-assessment.

This is not a test you pass or fail. It helps us understand your current comfort level with IT concepts, troubleshooting, documentation, and escalation. Your answers help us recommend the right training path and give your mentor a better idea of how to support you.

Answer honestly. It is completely okay if some of these topics are new to you.

## Section 3: IT Vocabulary

### Q8. In a school or workplace IT environment, what is a domain?

**Type:** Multiple choice  
**Category:** IT Vocabulary  
**Points:** 5

A. A website address only  
B. A managed network environment used for accounts, computers, and access  
C. A type of monitor cable  
D. A folder on the desktop  

**Correct Answer:** B

**Explanation:**

In this context, a domain helps an organization manage user accounts, computers, permissions, and access in a central way.

---

### Q9. What does computer imaging mean?

**Type:** Multiple choice  
**Category:** IT Vocabulary  
**Points:** 5

A. Taking a picture of a computer  
B. Preparing a computer with the required operating system, software, and settings  
C. Printing a computer label  
D. Changing the desktop background  

**Correct Answer:** B

**Explanation:**

Computer imaging prepares a computer with the standard operating system, software, settings, and configuration it needs before being used.

### Q10. SCCM or Configuration Manager is generally used for what?

**Type:** Multiple choice  
**Category:** IT Vocabulary

## Section 4: Beginner Troubleshooting

### Q13. A monitor says "No Signal." What should you check first?

**Type:** Multiple choice  
**Category:** Beginner Troubleshooting  
**Points:** 6

A. Reimage the computer  
B. Check power, display cable, monitor input/source, and whether the computer is on  
C. Delete the user profile  
D. Replace the computer immediately  

**Correct Answer:** B

**Explanation:**

A "No Signal" message is often related to power, cabling, monitor input/source, or whether the computer is actually sending video. These are beginner-safe checks.

---

### Q14. A keyboard is not working. What is a beginner-safe first step?

**Type:** Multiple choice  
**Category:** Beginner Troubleshooting  
**Points:** 6

A. Open the computer case  
B. Check the connection or try a known-working keyboard  
C. Reinstall Windows  
D. Change domain settings  

**Correct Answer:** B

**Explanation:**

Checking the connection or testing with a known-working keyboard is a safe first step. Opening the computer, reinstalling Windows, or changing system settings should not be done without approval.

---

### Q15. Which of these is usually beginner-safe?

**Type:** Multiple choice  
**Category:** Beginner Troubleshooting  
**Points:** 6

A. Guessing which image to use  
B. Changing system settings without approval  
C. Checking whether a monitor cable is connected  
D. Deleting old user folders  

**Correct Answer:** C

**Explanation:**

Checking a cable connection is usually safe. Guessing, changing settings, or deleting files can cause problems and should require approval.

---

### Q16. A computer is running slowly. What is the safest beginner response?

**Type:** Multiple choice  
**Category:** Beginner Troubleshooting  
**Points:** 7

A. Delete files until the computer is faster  
B. Document the symptoms, ask what the user was doing, and check beginner-safe items if instructed  
C. Reimage the computer immediately  
D. Ignore the issue because slow computers are normal  

**Correct Answer:** B

**Explanation:**

The safest beginner response is to document what is happening, collect basic context, perform only approved beginner-safe checks, and escalate when needed.

## Section 5: Workflow and Escalation

### Q17. You are asked to help image a computer, but you are not sure which image or workflow to use. What should you do?

**Type:** Multiple choice  
**Category:** Workflow and Escalation  
**Points:** 7

A. Pick the one that seems closest  
B. Stop and ask your mentor or the IT tech on duty  
C. Skip the imaging step  
D. Mark the computer complete  

**Correct Answer:** B

**Explanation:**

A new work-study student should not guess during imaging. If you are unsure which image or workflow applies, stop and ask your mentor or the IT tech on duty.

---

### Q18. You see an unfamiliar error while helping with a computer. What should you do?

**Type:** Multiple choice  
**Category:** Workflow and Escalation  
**Points:** 7

A. Keep clicking until something works  
B. Restart the process repeatedly without telling anyone  
C. Document the error and ask your mentor  
D. Ignore it  

**Correct Answer:** C

**Explanation:**

Unfamiliar errors should be documented and escalated. This helps the mentor understand what happened and prevents accidental mistakes.

---

### Q19. A user asks you a question and you do not know the answer. What should you do?

**Type:** Multiple choice  
**Category:** Workflow and Escalation  
**Points:** 8

A. Guess  
B. Tell them IT cannot help  
C. Ask your mentor or supervisor and document the question if needed  
D. Avoid the user  

**Correct Answer:** C

**Explanation:**

It is better to ask for help than to guess. A strong work-study student knows when to involve a mentor or supervisor.

---

### Q20. What should good ticket notes or mentor summaries include?

**Type:** Multiple choice  
**Category:** Workflow and Escalation  
**Points:** 8

A. "Fixed"  
B. Only the user's name  
C. The issue, what was checked, what happened, and what still needs to be done  
D. Nothing unless the issue is serious  

**Correct Answer:** C

**Explanation:**

Good ticket notes or mentor summaries should explain the issue, what was checked, what happened, and what still needs to be done. New students may draft this information for a mentor instead of updating the ticket/work-order system directly.
