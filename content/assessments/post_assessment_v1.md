# IT Work Study Launchpad Post-Assessment v1

## Purpose

This assessment helps measure what a new IT work-study student learned after completing the assigned Launchpad modules, checklists, and shadowing activities.

It is not meant to prove that a student is fully trained. It helps mentors understand whether the student is ready for beginner-safe tasks with appropriate supervision.

## Student Intro

You have completed the first Launchpad training path. This post-assessment helps you and your mentor see what you understand now, where you feel more confident, and what should still be reviewed.

Answer honestly. If you are unsure, say so. Good IT work includes knowing when to ask for help.

## Readiness Levels

| Score | Level | Mentor Action |
|---:|---|---|
| 0-59 | Needs More Foundation Review | Repeat key modules and shadow closely |
| 60-74 | Developing Readiness | Allow limited beginner-safe tasks with close guidance |
| 75-89 | Ready for Beginner-Safe Tasks | Approve supervised beginner-safe work |
| 90-100 | Strong Beginner Readiness | Approve supervised work and add next-step practice |

Readiness approval should still come from an authorized supervisor or mentor.

### Q10. An unfamiliar imaging error appears. What information should you collect before asking for help?

**Type:** Free response  
**Category:** Imaging Understanding  
**Points:** 10

**Strong Answer Should Include:**

- Device name or asset tag
- Exact error message or code
- What step was happening
- What the student was instructed to do
- Whether the process stopped or continued
- Confirmation that the student stopped and asked for help

**Mentor Review Guide:**

This question is not auto-scored. Review whether the answer captures context, exact error details, stopping point, and escalation.

## Section 6: Escalation Judgment

### Q13. Which situation should usually be escalated?

**Type:** Multiple choice  
**Category:** Escalation Judgment

A. A user says they cannot access a system they normally use  
B. A monitor cable is visibly unplugged and you were told to reconnect it

D. You are checking your own schedule  

**Correct Answer:** A

**Explanation:**

Access and permission issues should usually be escalated because they can affect security and user access.

### Q14. What should you do if you are unsure whether a task is beginner-safe?

**Type:** Multiple choice  
**Category:** Escalation Judgment  
**Points:** 8

A. Try it quietly  
B. Search randomly and follow the first result

**Explanation:**

Stopping and asking protects users, devices, data, and the team.
