# Week 1 Onboarding Checklist

## Purpose

This checklist helps a new IT work-study student move from first-day orientation into supervised beginner-safe practice.

By the end of Week 1, the student should understand basic IT vocabulary, know when to ask for help, complete assigned modules, practice draft documentation, and receive mentor feedback.

## Required Foundations

- [ ] Complete Common IT Words.
- [ ] Complete What Does IT Do?
- [ ] Complete Domain Basics.
- [ ] Complete SCCM / Configuration Manager Overview.
- [ ] Complete Computer Imaging Overview.
- [ ] Complete Ticket Basics.
- [ ] Complete Asset Tag Basics.
- [ ] Complete Hardware Basics.
- [ ] Complete How to Ask for Help.
- [ ] Complete Escalation Rules.

---

## Workflow Orientation

The mentor should review:

- [ ] How users ask IT for help.
- [ ] How tickets/work orders are used.
- [ ] Who may create, edit, close, or update tickets/work orders.
- [ ] How equipment movement is documented.
- [ ] How asset tags and inventory records are used.
- [ ] What tasks are beginner-safe.
- [ ] What tasks require training or authorization.
- [ ] What to do when a user is waiting.
- [ ] What to do when the student is unsure.

---

## Beginner-Safe Practice

Only complete items approved by the mentor.

- [ ] Identify common hardware at a workstation.
- [ ] Locate and record an asset tag exactly as shown.
- [ ] Check monitor power and input/source in a sample or supervised scenario.
- [ ] Check keyboard or mouse connection in a sample or supervised scenario.
- [ ] Observe a ticket or work order being updated by authorized staff.
- [ ] Draft a mentor summary for a sample hardware issue.
- [ ] Draft a mentor summary for a sample imaging issue.
- [ ] Practice escalating an unknown error.

---

## Imaging and Deployment Awareness

The student should be able to explain:

- [ ] What computer imaging means.
- [ ] Why different devices may need different images or workflows.
- [ ] Why guessing during imaging is risky.
- [ ] What to document when an imaging error appears.
- [ ] Why mentor approval may be required before marking a device ready.
- [ ] Which imaging actions are not beginner-safe.

---

## Documentation Practice

The student should practice writing draft notes or mentor summaries.

- [ ] Draft note includes the issue or request.
- [ ] Draft note includes device, location, or asset tag when appropriate.
- [ ] Draft note includes what was checked.
- [ ] Draft note includes what happened.
- [ ] Draft note includes what still needs to happen.
- [ ] Draft note avoids passwords or sensitive data.
- [ ] Draft note does not claim resolution if the student is unsure.
- [ ] Mentor reviewed at least two draft notes.

---

## Scenario Practice

Complete at least three scenarios.

- [ ] Monitor says No Signal.
- [ ] Keyboard or mouse is not responding.
- [ ] User cannot log in.
- [ ] Imaging error appears.
- [ ] Asset tag is missing or unreadable.
- [ ] User asks a question the student cannot answer.
- [ ] Student is unsure whether a task is allowed.

For each scenario, the student should answer:

1. What is the issue?
2. What beginner-safe information can be collected?
3. What should not be done without approval?
4. What should be documented?
5. Should this be escalated?

---

## Post-Assessment and Review

- [ ] Complete post-assessment.
- [ ] Review score and readiness level with mentor.
- [ ] Compare pre-assessment and post-assessment confidence.
- [ ] Identify concepts to revisit.
- [ ] Identify next beginner-safe tasks.
- [ ] Confirm whether the student is approved for supervised beginner-safe work.

---

## Week 1 Readiness Decision

Readiness does not mean the student is fully trained. It means the student is ready for beginner-safe tasks with appropriate supervision.

- [ ] Ready for supervised beginner-safe tasks.
- [ ] Needs more review before task approval.
- [ ] Needs additional shadowing.
- [ ] Needs supervisor follow-up.
